# উইকিমিডিয়া ব্যবহারকারী স্ক্রিপ্ট (Wikimedia user scripts)

এই ফোল্ডারে ড্যাশবোর্ডের পাশাপাশি ব্যবহারের জন্য উইকিমিডিয়া ব্যবহারকারী স্ক্রিপ্ট রাখা হয়। এগুলো ড্যাশবোর্ড সার্ভার থেকে পরিবেশিত হয় না; উইকিতে নিজের ব্যবহারকারী পাতায় কপি করে ব্যবহার করতে হয়।

## `vector-2022-mobile.js` — ভেক্টর ২০২২ মোবাইল ও ট্যাবলেট-বান্ধব (Vector 2022, mobile and tablet friendly)

ভেক্টর ২০২২ স্কিনে নিজস্ব রেসপন্সিভ বিন্যাস আছেই (ফোন ≤ ৬৩৯px, ট্যাবলেট ৬৪০–১১১৯px, ডেস্কটপ ≥ ১১২০px), আর মিডিয়াউইকি কোরে ছবি, থাম্বনেইল ও টেবিলের রেসপন্সিভ নিয়ম আছে `skin--responsive` ক্লাসের পেছনে। কিন্তু উইকিমিডিয়ার উইকিগুলোতে `$wgVectorResponsive` বন্ধ থাকায় পাতা পাঠানো হয় `<meta name="viewport" content="width=1120">` দিয়ে, ফলে ফোন বা ট্যাবলেটে ডেস্কটপ বিন্যাসটাই ছোট করে দেখায়। এই স্ক্রিপ্ট ব্রাউজার থেকে সেই রেসপন্সিভ মোড চালু করে এবং কয়েকটি ছোট সংশোধন যোগ করে:

- viewport = যন্ত্রের প্রস্থ; `<body>`-তে `skin--responsive`
- চওড়া টেবিল পাতাকে চওড়া না করে নিজের ভেতরে পাশাপাশি স্ক্রল করে (ফোন ও ট্যাবলেট)
- তথ্যছক (infobox) ও সাইডবার ফোনে পুরো প্রস্থ নেয়
- ফোনে একটু বড় লেখা (১৬px), ১৬px সার্চ ইনপুট (iOS-এ জুম আটকায়) ও বড় ট্যাপ-টার্গেট
- ফোনে এক সারির হেডার: ওয়ার্ডমার্ক (লোগো) লুকানো, মেনু বোতাম ও আইকনগুলো কাছাকাছি (আইকনের ফাঁক ৮px → ১px)
- ব্যবহারকারী মেনুতে “Mobile layout: on/off” (বাংলা ইন্টারফেসে “মোবাইল বিন্যাস: চালু/বন্ধ”) লিংক: এই যন্ত্রে বন্ধ/চালু করার জন্য

ডেস্কটপ প্রস্থে (১১২০px ও তার বেশি), অন্য স্কিনে এবং প্রিন্টে কিছুই বদলায় না। রং বদলায় না, তাই নাইট মোডেও সমস্যা নেই।

### ইনস্টল (Install)

**দ্রুততম উপায়:** পুরো ফাইলটি সরাসরি `User:<নাম>/vector-2022.js` পাতায় (ওই উইকিতে, শুধু ভেক্টর ২০২২ স্কিনে লোড হয়) অথবা সব উইকির জন্য `meta:User:<নাম>/global.js`-এ পেস্ট করুন। তাহলে ResourceLoader এটি আপনার অন্য স্ক্রিপ্টের সঙ্গে একই অনুরোধে, মিনিফাই করে, সংস্করণযুক্ত URL থেকে পাঠায়, যা ব্রাউজার সপ্তাহের পর সপ্তাহ ক্যাশে রাখে।

**বিকল্প:** এক কপি মেটায় `User:<নাম>/vector-2022-mobile.js` পাতায় রেখে `global.js` বা `common.js` থেকে আমদানি করুন:

```js
mw.loader.load( '//meta.wikimedia.org/w/index.php?title=User:<নাম>/vector-2022-mobile.js&action=raw&ctype=text/javascript&smaxage=86400' );
```

এতে `global.js` চলার পর আরেকটি আলাদা অনুরোধ লাগে, তাই বিন্যাস বদলাতে একটু দেরি হয় (নিচে “লোডের গতি” দেখুন)।

ফোনে উইকিমিডিয়া সাইট সাধারণত মোবাইল সংস্করণে (`bn.m.wikipedia.org`, মিনার্ভা স্কিন) পাঠিয়ে দেয়। ভেক্টর ২০২২ দেখতে হলে পাতার নিচের “ডেস্কটপ” লিংকে চাপুন; তারপর থেকে স্ক্রিপ্ট কাজ করবে। ট্যাবলেটেও একইভাবে।

### লোডের গতি (Loading speed)

স্ক্রিপ্ট চালু হওয়ার আগে এক মুহূর্ত ডেস্কটপ বিন্যাস দেখা যায়। কারণ viewport শুধু জাভাস্ক্রিপ্ট দিয়েই বদলানো যায় (CSS দিয়ে নয়), আর ব্যবহারকারী স্ক্রিপ্ট মিডিয়াউইকির নিজের জাভাস্ক্রিপ্ট (ResourceLoader) চালু হওয়ার পরেই চলে; পাতার HTML নামার পর মোবাইল নেটওয়ার্কে এতে এক-দুই সেকেন্ড লাগতে পারে। এটুকু কোনো ব্যবহারকারী স্ক্রিপ্টই এড়াতে পারে না। তবে বাকি দেরিটুকু কমানো যায়:

- `mw.loader.load( …action=raw… )` দিয়ে আমদানি করলে `global.js` আগে নামে ও চলে, তারপর স্ক্রিপ্টের জন্য আলাদা অনুরোধ যায় (মেটা থেকে হলে অন্য হোস্টে নতুন সংযোগসহ)। পুরো স্ক্রিপ্ট `vector-2022.js`/`common.js`/`global.js`-এ পেস্ট করলে এই ধাপটি উঠে যায়; স্ক্রিপ্ট যত আগে চলা সম্ভব তত আগেই চলে।
- `action=raw` পাতা ব্রাউজারে ডিফল্টভাবে ১৪ দিন ক্যাশে থাকে (উইকিমিডিয়ার `$wgCdnMaxAge`), কিন্তু লগ-ইন করা ব্যবহারকারীর জন্য সার্ভার `Cache-Control: private` পাঠায়, তাই CDN এটি কখনো ক্যাশে রাখে না এবং ক্যাশ ফুরালে প্রতিবার অ্যাপ সার্ভার থেকে আসে। URL-এ `&smaxage=86400` দিলে অন্তত বেনামি অনুরোধে CDN একদিন রাখে; `&maxage=<সেকেন্ড>` দিয়ে ব্রাউজারের ক্যাশ-সময়ও বদলানো যায়।
- স্ক্রিপ্ট নিজে ছোট (প্রায় ১৫ KB, মিনিফাই হলে অর্ধেকের কম) এবং প্রথমেই viewport বদলায়; বাকি কাজ (টেবিল মাপা) পরে হয়।

### অপশন (Options)

স্ক্রিপ্ট লোড হওয়ার আগে (যেমন `common.js`-এ `mw.loader.load` লাইনের উপরে) দিতে হয়; সবগুলোই ঐচ্ছিক:

```js
window.vector2022MobileConfig = {
	tables: true,   // চওড়া টেবিল স্ক্রলযোগ্য মোড়কে রাখা
	infobox: true,  // ফোনে তথ্যছক ও সাইডবার পুরো প্রস্থে
	text: true,     // ফোনে ১৬px লেখা (ভেক্টরের “Small” টেক্সট সাইজ থাকলে; Standard/Large বাছাই করা থাকলে বদলায় না)
	hideLogo: true, // ফোনে ওয়ার্ডমার্ক লুকিয়ে হেডার এক সারিতে রাখা (false দিলে লোগো থাকবে)
	menuLink: true, // ব্যবহারকারী মেনুতে চালু/বন্ধ লিংক
	labels: { on: 'Mobile layout: on', off: 'Mobile layout: off', tooltip: '…' }
};
```

চালু/বন্ধ অবস্থা ব্রাউজারের `localStorage`-এ (`vector-2022-mobile` = `off`) থাকে, উইকির পছন্দে নয়; তাই যন্ত্রভেদে আলাদা।

### কীভাবে কাজ করে ও কী ছোঁয় না (How it works, what it leaves alone)

- শুধু `mw.config.get( 'skin' ) === 'vector-2022'` হলে চলে; একবারের বেশি লোড হলেও একবারই কাজ করে।
- বিদ্যমান viewport ট্যাগে `device-width` থাকলে (যেমন `$wgVectorResponsive` চালু কোনো উইকি) তা বদলায় না; আগের মান `data-vector-2022-mobile-original`-এ রাখে।
- সব CSS `html.vector-2022-mobile` ক্লাসের ভেতরে এবং `max-width` মিডিয়া কোয়েরিতে; ডেস্কটপে কোনো নিয়ম খাটে না।
- টেবিল মোড়ক (`div.vector-2022-mobile-table.noresize`) কেবল সেই টেবিলে বসে যা নিজের জায়গার চেয়ে চওড়া, ভাসমান (float) নয়, `display: table` (পাশাপাশি রাখা `inline-table` নয়), অন্য টেবিলের ভেতরে নয় এবং আগে থেকে `.noresize`-এ নেই। `wikipage.content` হুক ও রিসাইজে (ট্যাবলেট ঘোরালে) আবার পরীক্ষা করে। `noresize` মিডিয়াউইকি কোরের নিজস্ব চিহ্ন, ভেক্টরের নিজের পরীক্ষামূলক টেবিল মোড়কও এটিই ব্যবহার করে।
- ছবির জন্য মিনার্ভার নিয়ম (`a > img { max-width: 100%; height: auto }`) ফোন ও ট্যাবলেটে; ইমেজম্যাপ (`usemap`) ও `.noresize` বাদ।

### সীমাবদ্ধতা (Limitations)

- ব্যবহারকারী স্ক্রিপ্ট পাতা আঁকার পরে চলে, তাই প্রথমে এক মুহূর্ত ডেস্কটপ বিন্যাস দেখা যায় (উপরে “লোডের গতি”)।
- পর্দার চেয়ে চওড়া যে জিনিস স্ক্রিপ্ট চেনে না (নির্দিষ্ট প্রস্থের টেমপ্লেট, টাইমলাইন ছবি ইত্যাদি) থাকলে মোবাইল ব্রাউজার ওই পাতাটি আবার ছোট করে দেখায়; কিছু লুকানো হয় না।
- ভিজ্যুয়াল এডিটর বা উইকিএডিটর মোবাইলের জন্য তৈরি নয়; সেগুলো স্ক্রিপ্টের আওতার বাইরে।

### পরীক্ষা (Testing)

- `npm test` — `test/userscript.test.js` স্ক্রিপ্টটি একটি ছোট নকল DOM ও নকল `mw`-এ চালিয়ে দেখে: অন্য স্কিনে কিছু করে না, viewport ও ক্লাস বসায়, কোন টেবিল মোড়ানো হয় আর কোনটি নয়, চালু/বন্ধ লিংক, ভাষা ও অপশন। ইন্টারনেট লাগে না।
- `npm run test:browser` — `test/browser/vector-2022-mobile-mock.html` (ভেক্টর ২০২২ ও কোরের আসল CSS মানের একটি নকল নিবন্ধ) হেডলেস Chromium-এ ফোন (৩৬০, ৪১২), ট্যাবলেট (৭৬৮, ১০২৪) ও ডেস্কটপ (১২৮০, ১৬০০) এমুলেশনে খুলে স্ক্রিপ্ট ঢুকিয়ে পরীক্ষা করে: viewport যন্ত্রের প্রস্থে বদলায়, পাতা পাশে স্ক্রল করে না, তথ্যছক/ছবি/সূত্র/টেবিল ঠিক থাকে, ডেস্কটপে আগের-পরের মাপ হুবহু এক, বন্ধ অবস্থা ও ঘোরানো। Playwright লাগে: `npm i --no-save playwright && npx playwright install chromium`। স্ক্রিনশট একটি অস্থায়ী ফোল্ডারে পড়ে (শেষে পথ দেখায়)।
